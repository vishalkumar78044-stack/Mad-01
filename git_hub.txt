                           GIT & GITHUB
                                │
          ┌─────────────────────┴─────────────────────┐
          │                                           │
        GIT                                       GITHUB
          │                                           │
          ├─ Tracks file changes                      ├─ Stores code online
          ├─ Version control system                   ├─ Backup of projects
          └─ Installed on computer                    └─ Collaboration

                                │
                                ▼
                      START A NEW PROJECT
                                │
        ┌───────────────────────┴───────────────────────┐
        │                                               │
        ▼                                               ▼
  Create Folder                                   Enter Folder

 mkdir myproject                               cd myproject

                                │
                                ▼
                        Initialize Git

                           git init

                                │
                                ▼
                        Check Changes

                          git status

                                │
                                ▼
                         Add Files
                                │
            ┌───────────────────┴───────────────────┐
            │                                       │
            ▼                                       ▼

     git add app.py                          git add .

      One File                               All Files

                                │
                                ▼
                           Commit
                                │

               git commit -m "Initial commit"

                                │
                                ▼
                      Create GitHub Repo
                                │

                    GitHub → New Repository

                                │
                                ▼
                    Connect Local to GitHub

   git remote add origin https://github.com/user/repo.git

                                │
                                ▼
                         First Push
                                │

                       git branch -M main
                                │
                                ▼
                    git push -u origin main

                                │
                                ▼
                       CODE ON GITHUB

   │
   └─ Save snapshot

   │
   └─ View history

   │
   └─ Upload code

git pull
   │
   └─ Download updates

git clone URL
   │
   └─ Download repository
